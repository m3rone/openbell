# Openbell

Openbell is a currently WiP simple PA/bell scheduler system.

## Features:
- Admin UI
- Simple deployment with a two executables or Docker
- Multi user support with roles
- Supports multiple outputs with individual controls for each

## Stack:
- htmx
- Go
- PocketBase

### Acknowledgements

This app is heavily inspired by [OpenChime](https://github.com/PKCubed/OpenChime).
